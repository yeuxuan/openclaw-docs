# 会话搜索

会话搜索解决的问题很简单：

```text
我记得以前聊过，但忘了具体在哪一段会话里。
```

它查的是已有会话内容和会话元数据，不是长期记忆系统本身。

---

## 它和记忆搜索不是一回事

很多人容易混掉这两个能力：

- 会话搜索：在“已经发生过的对话”里找
- 记忆搜索：在“被沉淀下来的长期记忆”里找

如果你只是想把以前那次聊天翻出来，会话搜索更直接。
如果你想让 Agent 在以后自动想起某些长期事实，重点还是记忆系统。

---

## 什么时候它最有用

适合这些场景：

- 你记得某个关键词，但不记得会话标题
- 你想回溯某次排障、某次讨论、某个旧方案
- 你需要先把旧上下文找出来，再决定要不要继续那条会话

---

## 一个实用心智模型

把 OpenClaw 想成两层：

1. 会话层：聊天记录、标题、上下文房间
2. 记忆层：被筛选、提炼、长期保存的事实

会话搜索偏第一层。
它更像翻聊天记录，不是翻知识卡片。

---

## 什么时候不要指望它

以下问题别让会话搜索硬背锅：

- “为什么 Agent 没主动记住这件事”
- “为什么长期偏好没有继承下来”
- “为什么模型没有自动回忆旧事实”

这些更可能是记忆配置、主动记忆、上下文组装的问题。
