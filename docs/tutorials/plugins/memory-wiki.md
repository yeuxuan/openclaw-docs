# Wiki 记忆插件

Wiki 记忆插件方向用于把结构化知识、团队文档或 wiki 内容变成 Agent 可检索资料。

关键问题：

- 哪些页面能索引？
- 谁有权限看？
- 多久同步一次？
- 搜索结果如何进入上下文？

不要把所有公司 wiki 一股脑丢给 Agent。先从小范围开始。

## 新手路线

1. 先选一小批非敏感文档。
2. 跑一次索引。
3. 用 `openclaw wiki search` 搜几个问题。
4. 确认结果准确，再扩大范围。

Wiki 记忆适合稳定知识，不适合临时聊天碎片。

## 看板提示重建或数据不全

每个看板的编译快照最多保留最新 2,500 张卡片，超过上限时会显示返回数与总数；这不等于原始资料丢失。看板请求不会扫描原始 vault 或等待完整编译。

自动恢复时看到“看板正在重建”，稍后刷新。若 `ingest.autoCompile: false`，来源变化或旧缓存会提示需要编译，运行：

```bash
openclaw wiki compile
```

然后刷新看板。`ingest.autoCompile` 默认开启，控制导入来源变化后是否重新生成编译结果。
